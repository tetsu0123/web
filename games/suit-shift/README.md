# SUIT SHIFT 2.0 — Strategy Edition

スマホ縦画面のトランプパズル。選んだマークをまとめて滑らせ、同じ数字に衝突した二枚を消す。今回の更新で手数制限・問題の選別基準・カジノ風の外観を変更した。

## 遊び方

- 通常は指定手数以内に全消去。最後の一手で全消去した場合は成功を優先する。
- 最初の20面は最短＋1手、21〜120面は検証済み最短手数が上限。
- 考える時間に制限はない。無効な移動は手数を消費しない。
- 戻す・ヒントは一挑戦につき各1回。戻すは一手だけ返し、使用回数は戻さない。やり直しは新しい挑戦になる。
- ヒントは残り手数以内の解法が確認できた場合だけ表示・消費する。探索打ち切りを「解なし」とは扱わない。
- 練習モードは手数・補助とも無制限。通常のクリア記録とは別に保存する。
- 補助なしで最短手数を達成したときだけ最短の印を付ける。
- スワイプ、カード選択＋方向ボタン、キーボードに対応。

## 問題の品質条件

120面すべての最短手数を幅優先探索で証明。117面には「最初に一組以上を消す別手順」を用意し、その初手後の最短継続も検証した。116面では、その初手を選ぶと最短より2手以上多く必要になる。単に無駄な往復を追加した比較ではない。

111面に、消去しない初手を含む最短解がある。116面は最短解に複数組の同時消去を含むことも採用条件にしている。反転・数字置換・マーク置換だけで一致する盤面は除外。

第5面: 最短5手・制限6手。先に消せる組を消す特定の初手を選ぶと最短でも7手必要。クリア後の「手順の差を見る」で両方の操作列を比較できる。

最短証明は操作ルールに対するもの。全員が面白いと感じることや実際の難易度を保証するものではなく、人による継続プレイ調整は未実施。

## デザイン

濃緑のフェルト、金の縁取り、生成りの紙、赤黒のカード、セリフ体の見出し。クラシック／ルビー／ノワールの三配色。実際の賭け・課金・広告はない。

## 実行

```sh
npm test
npm run build
npm start
# ブラウザで localhost:4173 を開く
```

`standalone.html`はCSS・ロジック・問題をまとめた単体版。配信版は`index.html`を開く。実行時の外部依存なし。Service Workerはゲームのディレクトリに限定する。

```sh
# C++17 compiler + Python 3 + Node.js
npm run generate
node scripts/verify-strategy.cjs
# playwright / Chromium がある環境で
python3 tests/strategy-browser.py
```

`generate`は1,709候補から採用し、`docs/curated-levels.json`を生成して`src/levels.js`へ可逆圧縮する。最短証明を打ち切った候補は採用しない。旧ランダム生成スクリプトは使用しない。

## テスト実績

- Nodeの15テスト成功。19,200操作の不変条件チェックを含む。
- 全120最短解と117本の初手制約付き最短解を、生成用C++とは別のJavaScript探索で再確認。237探索すべて成功。
- ブラウザ内で全120面を上限内に全消去。
- 手数切れ、失敗後の操作拒否、最後の一手での成功、戻す・ヒント制限、練習記録の分離、補助ありと最短達成の区別を確認。
- 保存済み状態を別ドキュメントへ復元して使用済み補助が復活しないことを確認。
- 320×568〜1440×1000の6サイズで盤面・操作欄・モード表示が画面内に収まる。
- JavaScriptページエラーなし。

ブラウザ検査はChromiumの`set_content`と明示的なメモリー内ストレージ代替による。実機iOS／Android、実ブラウザの永続保存、実HTTPオフライン再起動は未確認。旧版記録は元のキーに残し、新しい問題のクリア記録へ混ぜない。

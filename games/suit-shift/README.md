# SUIT SHIFT

縦画面・一人用のトランプパズル。既存サイトのファイルは変更せず、このフォルダだけで動作させる。

## 確定ルール
- 4列×5行。通常のトランプから重複のないカードを配置。
- カードをスワイプすると同じマークの全カードがその方向へ滑る。
- 同じ数字へ衝突すると二枚とも消える。違う数字・壁・盤面端で停止する。
- 前方から処理し、先行する消去によって空いた場所は同じ一手で通過できる。
- 補充、落下、ランダムな結果はない。すべて消せばクリア。
- 無制限の戻す・やり直す、一手先プレビュー、ヒント、自動保存。

## 実装方針
- 外部依存のないHTML/CSS/JavaScript。モバイルのブラウザで遊べる。
- ダークブルーの背景、生成りのカード、赤黒のマーク、シアンの選択表示。
- スワイプとタップ＋方向ボタン、キーボード操作を提供。
- 120面をオフライン探索で検証。配信中のランダム生成は行わない。
- 開発版は全120面無料。ストア課金は実装しない。
- 既存サイトから独立したService Workerスコープ。

## 検証
ゲームルールの単体テスト、全問題の解法再生、画面寸法の検査、ブラウザでの操作・保存・戻す・ヒント確認を行う。検証結果と既知の制約は完成版READMEに追記する。

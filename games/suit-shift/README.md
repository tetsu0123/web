# SUIT SHIFT

同じマークをまとめて動かし、同じ数字をぶつけて消すトランプパズル。縦画面ブラウザ版。全120面、広告・課金なし。

## 遊び方
カードから上下左右へスワイプすると、同じマークの全カードが端か障害物まで滑ります。同じ数字に衝突すると二枚とも消えます。違う数字と固定壁は動かせません。補充・落下はなく、全消去でクリアです。

設定からタップ＋方向ボタンに切り替えられます。PCではカード選択後に矢印キー、1〜4でマーク選択、Zで戻す、Hでヒントを使えます。

## 実装済み
- 120面、固定壁、同じ数字四枚の問題、目標手数、全ステージ選択。
- 移動先プレビュー、無制限の戻す・やり直す、探索上限を明示するヒント。
- 自動保存、セーブのJSON書き出し・検証付き読み込み。
- 三種類の配色、紙面テクスチャ、移動・消去アニメーション。
- Web Audio効果音・BGM、対応端末向け振動、動きを減らす設定。
- フォルダ内だけを扱うService WorkerとWeb App Manifest。

## 起動・開発
Node.js 20以上。実行時の外部ライブラリ、npm依存パッケージ、ビルドは不要です。

```sh
cd games/suit-shift
npm test
npm run build
npm start
```

`npm start`はPython 3のHTTPサーバーを4173番で起動します。ブラウザで `http://localhost:4173/` を開いてください。`npm run build`は、ゲームロジックと画面を一ファイルにまとめた`standalone.html`を生成します。直接開く場合の保存・Worker対応はブラウザに依存します。

`npm run generate`は固定シードで問題を再生成して`src/levels.js`を置き換えます。通常の起動時には生成しません。再生成後はテストとビルドを実行してください。

ブラウザテストはPython版PlaywrightとChromiumを別途必要とします。

```sh
python -m pip install playwright
python -m playwright install chromium
python tests/browser_test.py
```

既存Chromiumを使う場合は`CHROMIUM_PATH`を指定できます。

## 検証結果
- Node単体テスト13件、失敗0件。
- 19,200操作の不変条件、入力不変性、プレビューと実結果の一致を確認。
- 全120面の解法をロジックとブラウザ上のアプリ制御の両方で再生し、全消去を確認。
- 実ポインター操作、ヒント、戻す、設定、破損セーブ拒否を確認。
- 320×568〜1440×1000の六画面サイズで盤面と操作ボタンが収まることを確認。
- 37面は最短手数を証明済み。それ以外の目標手数は確認済み解法の長さであり、最短とは限りません。

実行環境でURL移動が制限されているため、ブラウザ試験はHTML直接読み込みと明示的なメモリ内ストレージ代替を使用しました。保存のシリアライズと新しい文書への復元は確認済みですが、実際のHTTP再読み込み、Service Worker導入後のオフライン起動、iOS Safari、Android実機の振動・インストールは未確認です。記録は`docs/browser-report.json`にあります。

難度の人間による調整、継続率、購入率は未検証です。ネイティブアプリ・ストア課金・英語UIへの完全翻訳はこの開発版に含みません。
